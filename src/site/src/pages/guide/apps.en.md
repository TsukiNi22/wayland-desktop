Five apps, the same in every style, skinned by its colors.

## Files {#files}

- Places on the left, path at the top (click a part to go back), filter, grid / list view.
- Click: preview on the right. Double-click: a folder opens, a text / code / image file opens in the viewer, a track plays.
- The file system is shared with the terminal: `mkdir`, `touch`, `rm` show up in Files at once.

## Browser {#browser}

- Tabs (<kbd>+</kbd>, <kbd>×</kbd>), back / forward / reload / home, an address bar.
- Pages: `poc://home` (search + shortcuts of the style), `poc://news`, `poc://video`, `poc://wiki`; anything else typed is a search.

## Terminal {#terminal}

- <kbd>↑</kbd> <kbd>↓</kbd> history, <kbd>Tab</kbd> completion (commands and paths), <kbd>Ctrl</kbd>+<kbd>L</kbd> clear,
  <kbd>Ctrl</kbd>+<kbd>C</kbd> cancel.
- `help` lists the commands; every style adds its own: [terminal commands](page:terminal-commands#kit).

## Music {#music}

A small synth plays the tracks of the style live (no audio file): play / pause / previous / next, the list, a visualizer.
The styles react to it: the Miku character sings the notes, the Ado box pulses on every kick, the tmux pane shows the bars.
How it works: [the synth](page:synth#tracks).

> [!NOTE]
> Browsers only allow sound after a click on the page: press play once.

## Settings {#settings}

| Setting | Effect |
|---|---|
| Accent | the accent color of the whole style |
| Wallpaper | the backgrounds of the style |
| Animations | turns the motion off |
| Tiling layout | floating or tiling windows |
| Do not disturb | hides the notifications |
| Style switches | ex: scanlines, character, falling petals |
| Volume | volume of the synth |
