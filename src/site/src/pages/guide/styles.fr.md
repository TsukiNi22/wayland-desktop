Chaque style est une page : le kit commun, ses couleurs, ses widgets et ses interactions.

## Système {#system}

:::html
<figure><img src="system-desktop.jpg" alt="Système" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- Barre flottante en pastilles (façon Waybar) : espaces de travail = situations, calendrier sur l'horloge, CPU / mémoire / réseau en direct.
- Moniteur système en direct : un clic sur un processus le termine.
- Réglages rapides qui marchent : style sombre / clair, lumière de nuit, ne pas déranger, mosaïque, luminosité, profil d'énergie.

Ouvrir : [system.html](https://tsukini22.github.io/wayland-desktop/poc/system.html)

## Dev / bas niveau {#dev}

:::html
<figure><img src="dev-desktop.jpg" alt="Dev / bas niveau" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- Un débogueur jouable : pas à pas (`si`), continuer, points d'arrêt (clic sur une ligne), registres et drapeaux qui changent, mémoire et pile.
- Le programme affiche vraiment ses `printf` dans la fenêtre stdout ; fond en dump hexadécimal, horloge binaire, fond CRT ambre.
- Écran de verrouillage façon BIOS.

Ouvrir : [dev.html](https://tsukini22.github.io/wayland-desktop/poc/dev.html)

## Ado / rose bleue {#jpop}

:::html
<figure><img src="jpop-desktop.jpg" alt="Ado / rose bleue" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- Ado Box : une cage rétroéclairée sur un mur marbré rouge / bleu, la silhouette se cambre avec la musique.
- Ado TV : les clips officiels, les chansons d'Uta, les reprises 歌いました, les lives et streams de sa chaîne, le live en cours, les autres plateformes.
- Roses bleues 3D qui tombent (cliquez-en une), tampon うっせぇわ, vœux qui éclosent, frise, autocollants, thème Uta.

Ouvrir : [jpop.html](https://tsukini22.github.io/wayland-desktop/poc/jpop.html)

## Terminal / better-tty {#tty}

:::html
<figure><img src="tty-desktop.jpg" alt="Terminal / better-tty" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- Pas de bureau : mosaïque façon tmux, <kbd>Ctrl</kbd>+<kbd>b</kbd> puis flèches / `c` / `x` / `z` / `d` / un chiffre, mode EDIT / CONTROL dans la barre.
- Login getty comme verrouillage, navigateur façon w3m, `git`, `cmake` (compilation animée), `nvim`.
- Volets btop et calendrier, couleurs rose-pine comme la configuration tmux.

Ouvrir : [tty.html](https://tsukini22.github.io/wayland-desktop/poc/tty.html)

## Miku {#miku}

:::html
<figure><img src="miku-desktop.jpg" alt="Miku" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- L'illustration officielle de KEI (ou un dessin animé dans les réglages) saute au tempo et chante les notes.
- Éditeur vocal : dessinez une mélodie sur la grille, elle la chante ; BPM et forme d'onde.
- Maintenez le bouton du rayon pour le charger, relâchez : MIKU MIKU BEAM, pluie de poireaux à pleine puissance.

Ouvrir : [miku.html](https://tsukini22.github.io/wayland-desktop/poc/miku.html)

## Photographe {#photographer}

:::html
<figure><img src="photographer-desktop.jpg" alt="Photographe" loading="lazy" width="1280" height="720" style="width: 100%; height: auto; border-radius: 8px"></figure>
:::

- Mur de photos à gauche et à droite, pellicule : un clic affiche une photo, la visionneuse les parcourt (flèches, <kbd>Échap</kbd>).
- Vrai histogramme RVB calculé depuis la photo affichée, diaporama, mode noir et blanc.
- Verrouillage façon viseur : grille des tiers, collimateurs, réglages de prise de vue.

Ouvrir : [photographer.html](https://tsukini22.github.io/wayland-desktop/poc/photographer.html)
