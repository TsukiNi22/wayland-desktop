Cinq applis, les mêmes dans chaque style, habillées de ses couleurs.

## Fichiers {#files}

- Emplacements à gauche, chemin en haut (un clic sur une partie y revient), filtre, vue grille / liste.
- Clic : aperçu à droite. Double-clic : un dossier s'ouvre, un fichier texte / code / image s'ouvre dans la visionneuse, un morceau se joue.
- Le système de fichiers est partagé avec le terminal : `mkdir`, `touch`, `rm` apparaissent tout de suite dans Fichiers.

## Navigateur {#browser}

- Onglets (<kbd>+</kbd>, <kbd>×</kbd>), précédent / suivant / recharger / accueil, une barre d'adresse.
- Pages : `poc://home` (recherche + raccourcis du style), `poc://news`, `poc://video`, `poc://wiki` ; tout autre texte est une recherche.

## Terminal {#terminal}

- <kbd>↑</kbd> <kbd>↓</kbd> historique, <kbd>Tab</kbd> complétion (commandes et chemins), <kbd>Ctrl</kbd>+<kbd>L</kbd> effacer,
  <kbd>Ctrl</kbd>+<kbd>C</kbd> annuler.
- `help` liste les commandes ; chaque style ajoute les siennes : [commandes du terminal](page:terminal-commands#kit).

## Musique {#music}

Un petit synthé joue les morceaux du style en direct (aucun fichier audio) : lecture / pause / précédent / suivant, la liste,
un visualiseur. Les styles y réagissent : le personnage Miku chante les notes, la cage d'Ado pulse à chaque temps, le volet
tmux affiche les barres. Le fonctionnement : [le synthé](page:synth#tracks).

> [!NOTE]
> Les navigateurs n'autorisent le son qu'après un clic sur la page : appuyez une fois sur lecture.

## Réglages {#settings}

| Réglage | Effet |
|---|---|
| Accent | la couleur d'accent de tout le style |
| Fond | les fonds du style |
| Animations | coupe les animations |
| Mosaïque | fenêtres libres ou en mosaïque |
| Ne pas déranger | masque les notifications |
| Interrupteurs du style | ex : lignes de balayage, personnage, pétales |
| Volume | volume du synthé |
