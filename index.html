Desktop POCs

Six desktop styles built on one small kit (HTML / CSS / JS): windows, lock screen, files, browser, terminal, music and settings work for real in every style. Open a page full screen (F11). Documentation

Everywhere

Scenes: keys 1–7 or the bar at the bottom left (desktop, lock, files, browser, terminal, music, settings).
Windows: drag by the title bar, resize from the corner, double-click to maximize, minimize / close, reopen from the dock or the task list.
Launcher: Ctrl+Space, type, Enter. Right-click the desktop for the context menu.
Terminal: help, ls, cd, cat, tree, neofetch, open, play, mkdir, lock, history with ↑ ↓, completion with Tab, plus commands of each style.
Files: click to preview, double-click to open (text, images, music), filter, grid / list. Browser: tabs, address bar, search, links, back / forward.
Music: a small synth plays original tracks live; the style reacts to the beat. Settings: accent color, wallpaper, tiling layout (Hyprland-like), animations, volume.

Motion inspired by Hyprland (popin windows with an overshoot curve, sliding workspaces, animated gradient border) and Waybar / Quickshell rices (pill modules).
